# Sites Nathan

Sites feitos pelo Nathan para clientes. Cada pasta é um site estático (HTML/CSS/JS) pronto para a Vercel; a parte publicada fica em `site/`.

- `site jw brinquedos/`: JW Festas, aluguel de brinquedos infláveis em Campo Grande (RJ).
- `site dani clara/`: Dani & Clara Brinquedos.
- `site fp brinquedos/`: FP Brinquedos & Diversão, aluguel de brinquedos, Linha Luxo e SPA infantil em Bangu, Realengo e Padre Miguel (RJ).

Veja o `README.md` e o `memoria.md` de cada pasta para detalhes, pendências e como publicar.
